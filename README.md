# Guess The Tech Quiz Game

A premium, interactive, web-based "Guess the Company" game designed for a live college tech-club orientation. The game features a polished, bright game-show interface designed for a projector display, complete with animations, sound effects, multiple-choice options, and host controls.

## Features

- **20 Tech Company Questions**: Emojis and text hints to guess popular tech companies.
- **Multiple Choice**: 4 distractor options per question that shuffle automatically.
- **Host Controls**: Full control over revealing answers, starting/pausing the 30-second timer, and navigating questions.
- **Dynamic Scoring**: Award points (+10) to multiple players manually during gameplay.
- **Interactive Timer**: 30-second timer with intense pulsing and sound effects during the final seconds.
- **Keyboard Shortcuts**: Control the entire game without a mouse (Space for Timer, A/B/C/D for options, V to Reveal, N for Next).
- **Responsive Light Theme UI**: Beautiful glassmorphism cards, soft drop shadows, and clean modern aesthetics.

## Tech Stack

- **Framework**: React.js + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **No Backend**: All game state runs locally!

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.
